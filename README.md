# ReyPlugins

A collection of [Dalamud](https://github.com/goatcorp/Dalamud) plugins by ReyAlex.

## Install

Add this URL in Dalamud **Settings → Experimental → Custom Plugin Repositories**:

```text
https://raw.githubusercontent.com/reyalexffxiv/ReyPlugins/main/pluginmaster.json
```

Save/refresh, then install any available plugin through the Dalamud plugin installer.

## Available Plugins

- **Venue Host** — Tools for hosting FFXIV venue events.
- **Bar Game** — `/random` jackpot game management.
- **Raffle Game** — Raffle ticket sales and winner draws.
